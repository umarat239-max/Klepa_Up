# Klepa Up — Telegram-бот + Mini App (версия 3)

Ваше приложение + сервер, бот, база, банк, QR-коды, чаты, официальный канал, поддержка, отзывы и админ-панель.

## Файлы (все в корне, без папок)
| Файл | Что это |
|---|---|
| `index.html`, `app.css`, `app.js` | ваше мини-приложение (оригинал, шрифты и картинки внутри) |
| `extra.js`, `extra.css` | профиль, поддержка, отзывы, админ-панель, обнуление, награды |
| `bank.js` | банк: переводы по @username, QR-код, сканер, история и аналитика |
| `social.js` | список чатов, общий чат, официальный канал |
| `server.js` | бот (webhook), основной API, раздача приложения |
| `api2.js` | банк, QR, чат, канал, загрузка фото и видео |
| `package.json`, `package-lock.json` | зависимости |
| `render.yaml` | автонастройка Render (сервис + база Postgres) |
| `env.example` | список переменных окружения |

## Обновление существующего проекта (данные не теряются)
1. На GitHub замените файлы: загрузите все 14 файлов с заменой (Add file → Upload files).
2. Render сам пересоберёт сервис. База остаётся прежней, игроки, балансы, промокоды, отзывы и роли сохраняются.
3. Если игрок открыл приложение на новом устройстве или после смены бота и его прогресс не подтянулся из облака, приложение само восстановит звёзды и подарки из копии на сервере (копия обновляется каждые 15 секунд).

## Переход на нового бота
1. Render → сервис → Environment: поставьте новые `BOT_TOKEN` и `OPENROUTER_KEY`, проверьте `PUBLIC_URL` (обязательно с `https://`). Остальное не трогайте, `DATABASE_URL` оставьте прежним.
2. @BotFather → новый бот → **Configure Mini App / Main App** → укажите `PUBLIC_URL`. Именно это приложение бот теперь открывает кнопкой в сообщении и реферальными ссылками.
3. **Добавьте нового бота администратором в канал @KlepaUp**, иначе подписки приглашённых проверить нельзя.
4. Откройте бота и нажмите /start. Сервер сам поставит webhook и сбросит старую кнопку меню.
5. Старого бота можно отключить: `/revoke` в @BotFather.

Токены и ключи вписывайте только в переменные Render, в GitHub их выкладывать нельзя.

## Что нового
- **Два нерабочих «мини-аппа» у бота исправлено:** бот больше не открывает приложение через `web_app`-кнопки. В сообщении теперь одна кнопка-ссылка на главное мини-приложение (то, что у вас открывается из профиля бота), а кнопка меню сброшена в стандартную.
- **Подписка на канал:** проверка принимает всех участников, а если бот не может проверить (нет прав в канале), владельцу приходит сообщение с причиной, а игроку показывается понятный текст вместо «вы не подписаны». В админ-панели на вкладке «Обзор» есть диагностика: бот, канал, права, главное приложение.
- **Банк** (Профиль → Банк): переводы звёзд по @username или ID, комментарий, комиссии нет, квитанции, история с фильтрами и поиском по юзернейму, итоги и график за 7 дней. Получатель сразу видит звёзды в приложении и получает сообщение от бота.
- **QR-код:** красивый QR с вашим профилем (можно задать сумму). Друг сканирует его камерой телефона или кнопкой «Сканер», открывается приложение, получатель и сумма подставлены.
- **Чаты** (Профиль → Чаты): список как в мессенджерах (канал, общий чат, поддержка) с последними сообщениями и счётчиками непрочитанного.
  - Общий чат: ответ на сообщение свайпом вправо, реакции, фото и видео с подписью, удаление своих сообщений, профиль игрока по нажатию на имя.
  - Официальный канал внутри приложения: посты с фото и видео, реакции, настоящие просмотры (один игрок считается один раз), число участников, подписка. Публикуют только админы с правом «Канал», можно уведомить подписчиков через бота.
- **Админ-панель:** новое право «Канал», вкладка «Переводы» (все переводы игроков), диагностика подписки.
- **ИИ-помощник** знает про банк, QR, чаты, канал, рефералку с подпиской, промокоды, роли и обнуление, а также про вашего игрока (юзернейм, ID, число приглашённых).

## Права админов
Игроки, Звёзды, NFT, Промокоды, Баны и чат, Роли, Поддержка, Отзывы, Обнуление, Рассылка, Канал. Владелец (`ADMIN_IDS`, по умолчанию 1424001997) имеет все права всегда.

## Важно знать
- Баланс и подарки хранятся в приложении игрока, сервер получает копию каждые 15 секунд. Перевод проверяется по последнему балансу игрока, который передаёт приложение; это тот же уровень доверия, что и у остальной игры.
- Фото до 4 МБ (сжимаются автоматически), видео до 12 МБ. Файлы хранятся в базе Postgres.
- Бесплатная база Render живёт 30 дней и вмещает около 1 ГБ. Для постоянной работы возьмите платный план или внешний Postgres (Neon, Supabase) и вставьте его адрес в `DATABASE_URL`.
- Без `DATABASE_URL` сервер пишет данные в `data.json` и папку `media` (удобно для теста; на Render они пропадут при перезапуске).
- Локальный запуск: `npm install`, затем `BOT_TOKEN=... PUBLIC_URL=... node server.js`.
